## 💼 How I Work

✅ I lead with **architecture-first thinking**—understanding the problem space before writing code.

✅ I create **clean abstractions** that hide complexity from consumers while remaining flexible under the hood.

✅ I ship **design-system-driven UI** where every component is reusable, documented, and battle-tested.

✅ I invest in **code quality through reviews**, mentorship, and shared standards across teams.

## 🧠 Engineering Principles

**⚖️ Systems over shortcuts**  
Every decision is evaluated against long-term maintainability, not just immediate delivery.

**🚀 Performance is a feature**  
Fast UIs aren't optional—they're fundamental to user experience and business outcomes.

**📈 Leave it better**  
Refactor as you go. Every commit should raise the bar, even slightly.

**🤖 Automate the boring**  
If you're doing it twice manually, it should be automated.
